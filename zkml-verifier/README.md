# zkSalaria ZKML Verifier Service

Zero-Knowledge Machine Learning proof verification service for zkSalaria payroll system.

## Overview

This service verifies EZKL proofs generated by employees and creates attestations that can be submitted to the Midnight blockchain.

## Setup

### 1. Install Dependencies

```bash
npm install
```

### 2. Configure Environment

Copy `.env.example` to `.env` and configure:

```bash
cp .env.example .env
```

Edit `.env`:
```bash
PORT=3001
VK_PATH=../zkml/examples/01-simple-threshold/vk.key
SETTINGS_PATH=../zkml/examples/01-simple-threshold/settings.json
VERIFIER_SECRET_KEY=your-32-byte-hex-key-here
```

### 3. Start Development Server

```bash
npm run dev
```

The server will start on `http://localhost:3001`

## API Endpoints

### GET /health
Health check endpoint

**Response:**
```json
{
  "status": "ok",
  "service": "zkml-verifier",
  "timestamp": 1234567890,
  "verifier_pubkey": "configured",
  "ezkl_available": true
}
```

### GET /api/zkml/status
Get verifier status and public key

**Response:**
```json
{
  "service": "zkml-verifier",
  "verifier_pubkey": "abc123...",
  "ezkl_available": true,
  "timestamp": 1234567890
}
```

### POST /api/zkml/verify-proof
Verify an EZKL proof and create attestation

**Request:**
```json
{
  "proof": {
    "proof": "...",
    "instances": [[...]]
  },
  "publicInputs": {
    "employee_id": "0x123...",
    "threshold": 5000,
    "txids": ["0xTX001", "0xTX002"],
    "merkle_root": "0xMERKLE..."
  }
}
```

**Response:**
```json
{
  "success": true,
  "attestation": {
    "employee_id": "0x123...",
    "threshold": "5000",
    "txids": ["0xTX001", "0xTX002"],
    "merkle_root": "0xMERKLE...",
    "timestamp": 1234567890,
    "attestation_hash": "0xHASH...",
    "verifier_secret": "0xSECRET...",
    "verifier_pubkey": "0xPUBKEY..."
  }
}
```

## Testing

### 1. Check Health

```bash
curl http://localhost:3001/health
```

### 2. Check Status

```bash
curl http://localhost:3001/api/zkml/status
```

### 3. Verify Proof

First, generate a proof using Example 1:

```bash
cd ../zkml/examples/01-simple-threshold
uv run python generate_proof_python.py
```

Then verify it:

```bash
curl -X POST http://localhost:3001/api/zkml/verify-proof \
  -H "Content-Type: application/json" \
  -d @proof.json
```

## How It Works

1. **Employee generates proof** (locally with EZKL)
2. **Employee sends proof to verifier** (this service)
3. **Verifier checks proof with EZKL** (calls EZKL CLI)
4. **Verifier creates attestation** (Midnight-style hash commitment)
5. **Employee receives attestation**
6. **Employee submits attestation to Midnight contract**

## Security

- Verifier secret key is used to create attestations
- Each attestation is unique (includes timestamp)
- The contract verifies the attestation came from trusted verifier
- EZKL verification ensures ML computation was correct
